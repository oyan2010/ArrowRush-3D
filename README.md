# ArrowRush 3D — Puzzle Master

A spatial logic puzzle game built with Flutter. Clean architecture, BLoC state management, local persistence with Hive, and full sound + ads integration. One codebase, three platforms: Android, Web, and Windows.

## Highlights

- **Clean architecture** — `core`, `data`, `domain`, `presentation` layers under `lib/`
- **State management** — flutter_bloc + equatable for predictable game state
- **Local storage** — Hive for progress and settings
- **Polished gameplay** — custom physics, sound effects (audioplayers), and Google Mobile Ads
- **Multi-platform** — Android, Web, and Windows from one codebase

## Run Locally

```bash
flutter pub get
flutter run
```

## Tech Stack

Flutter · Dart · BLoC · Hive · google_mobile_ads
